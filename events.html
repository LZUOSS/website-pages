这些活动从哪里来？

开源社区活动基础数据来自 Open Source Deadlines 开源数据仓库 ↗。同时直接同步 Codeforces 官方 API ↗ 与 AtCoder 官方赛程 ↗；国内竞赛和学术会议则根据主办方官网补充，每条记录保留来源与核对或抓取日期。

这是发布时同步的数据快照，不是实时报名状态。倒计时随当前时间计算；明确的长期机会单独保留；没有截止日不代表已结束。长期机会超过 30 天未复核，会自动转入“状态待核实”。过去的限期记录归入历史，但不据此判断其资料是否仍可学习。仅公布日期的节点显示天数，不虚构具体截止时刻。
